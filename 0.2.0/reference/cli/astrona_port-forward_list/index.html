    Astrona port forward list

    astrona port-forward list¶

    List port forwards and their status (all labs, or one)

    astrona port-forward list [lab-name] [flags]

    Examples¶

      astrona port-forward list
  astrona pf list my-lab -o wide
  astrona pf list --watch

    Options¶

      -h, --help            help for list
  -o, --output string   Output format: 'wide' adds namespace, PID and last error
  -w, --watch           Refresh every 2s until Ctrl-C

      --git-ref string   Git branch, tag, or commit to check out (used with --git; default: the repo's default branch)
      --trust            Approve running a remote (--git / URL) lab without asking — for CI; review the lab first
